# AstroCiel

Application web qui utilise la position GPS ou une ville pour afficher :

- la météo astronomique de la soirée ;
- un score de qualité d'observation ;
- le meilleur créneau horaire ;
- les constellations actuellement visibles au-dessus de l'horizon.

## Utilisation

Ouvrez `index.html` dans un navigateur moderne, ou servez le dossier avec un serveur HTTP statique.

Version publiée : https://astrociel-observation.nicolas-herr9812.chatgpt.site

Les prévisions météo proviennent d'Open-Meteo. Les calculs astronomiques sont effectués localement dans le navigateur.
